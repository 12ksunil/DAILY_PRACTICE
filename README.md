In this project, I wrote a Python program to calculate how many times each number is repeated in a list using loops.

* In the first and second loops (`i` and `j`), the program counts the frequency of each number in the list.
* In the third loop (`k`), the program checks whether the number has already appeared before. This prevents duplicate results from being printed.

### Example

Input:

```python
a = [1, 2, 3, 4, 4, 4, 5, 5, 5, 3, 2]
```

Output:

```text
1 1
2 2
3 2
4 3
5 3
```
